## 1. Visual Architecture & Domain Principles

**Style:** Data-Dense Dashboard
**Primary Principle (`AGENTS.md`):** *SQL calcula; la IA explica.* Every view MUST visually separate deterministic financial metrics from statistical alerts and generative explanations:

| Layer | Badge Token | Visual Cue | Meaning |
|---|---|---|---|
| **Dato SQL** | `badge-sql` | Primary Blue (`#1E40AF` text on `#DBEAFE`/`#EFF6FF`) | Deterministic metrics computed in Snowflake (`GOLD.KPI_MENSUAL`, `SILVER.TRANSACCIONES`). |
| **Alerta Estadística** | `badge-alert` | Amber / Red (`#B45309` on `#FEF3C7` or `#DC2626` on `#FEE2E2`) | Rule/statistical deviations flagged in `GOLD.ANOMALIAS`. |
| **Explicación IA** | `badge-ai` | Slate/Indigo tint (`#334155` on `#E9EEF6` with Sparkles SVG icon) | Narrative generated by Groq (`openai/gpt-oss-120b`) strictly from SQL context. |

**Mandatory Context Visibility:**
- Always display **active analysis period** (`YYYY-MM` range), **applied filters** (`Categoría`, `Área`), **currency unit (`COP`)**, and **last update timestamp** in the top context bar.
- Never truncate or obscure SQL query traceability in the Analyst view.

## 3. Typography & Financial Number Discipline

- **Heading & Numeric Font:** `Fira Code` (`font-mono`) — used for KPI values, currency tables, percentages, SQL trace blocks, and compact technical headers.
- **Body & UI Font:** `Fira Sans` (`font-sans`) — used for navigation, filter labels, chat prose, and executive reports.
- **Tabular Figures Mandatory:** Every COP amount, percentage delta, and table column MUST apply `tabular-nums` (`font-variant-numeric: tabular-nums`) and right-align inside tables (`text-right`).

| Element | Tailwind Classes | Notes |
|---|---|---|
| Topbar App Title | `font-sans text-lg font-bold tracking-tight text-foreground` | Never exceed 1 `h1` per active view |
| Section Title (`h2`) | `font-sans text-base font-semibold text-foreground` | Paired with provenance badge (`Dato SQL` / `Explicación IA`) |
| KPI Value | `font-mono text-2xl font-bold tracking-tight tabular-nums text-ink` | Always include `COP` unit or explicit axis label |
| KPI Delta / Margin | `font-mono text-xs font-semibold tabular-nums` | Include sign (`+` / `-`) and directional SVG arrow |
| Table Header | `font-sans text-xs font-semibold uppercase tracking-wider text-muted-foreground` | Sticky top inside `overflow-x-auto` container |
| Table Numeric Cell | `font-mono text-sm tabular-nums text-right text-ink` | Thousand separators (`180.500.000 COP` or `180,5 M COP`) |
| SQL Trace Code Block | `font-mono text-xs leading-relaxed bg-slate-900 text-slate-100 rounded-lg p-3 overflow-x-auto` | Read-only expandable `<details>` in Analyst & Report views |

## 4. Layout Shell & Application Views (4 Tabs)

Replace marketing-landing patterns completely with a **sticky-sidebar + compact-topbar BI workspace**:

- **Shell Grid (`>= 1024px`):** Fixed or collapsible left navigation rail (`w-60`, `bg-card border-r border-border z-sticky`) + main workspace (`flex-1 min-w-0 bg-background`).
- **Mobile (`< 1024px`):** Top bar (`z-header`) with drawer/horizontal scrollable tab bar (`375px`, `768px` tested, zero horizontal body overflow).
- **Sticky Global Context & Filter Bar (`z-sticky`):**
  - Left: Period selector (`Desde YYYY-MM`, `Hasta YYYY-MM`), `Categoría`, `Área`, Reset button.
  - Right: Active period pill, currency indicator (`COP`), Snowflake/Groq connection status dot + label, last updated timestamp.

### View Map (`frontend/src/App.jsx` Tabs)

1. **Resumen Financiero (`Dashboard`)**
   - Row 1: 4-column Bento KPI strip (`grid-cols-1 sm:grid-cols-2 xl:grid-cols-4 gap-3`) — *Ingresos Totales*, *Gastos Totales*, *Utilidad Neta*, *Margen (%)*, each showing MoM variation + `Dato SQL` badge.
   - Row 2: 12-col split (`grid-cols-1 lg:grid-cols-12 gap-4`) — Left `lg:col-span-8`: Monthly Trend line/bar chart (*Ingresos vs Gastos vs Utilidad*); Right `lg:col-span-4`: Expense Breakdown by Category/Area horizontal bar chart.
   - Row 3: Compact monthly breakdown table wrapped in `overflow-x-auto` with hover row highlight (`hover:bg-muted/50`).
2. **Agente Analista (`Natural-Language SQL Q&A`)**
   - Prompt suggestions grid (4 clickable Spanish financial questions).
   - Split answer card:
     - Top/Left: **Explicación IA** narrative (`bg-muted/60 border border-border rounded-xl p-4`) with disclaimer badge.
     - Bottom/Right: **Dato SQL** deterministic result table + optional Plotly mini-chart + collapsible **Consulta SQL ejecutada** (`<details>`).
3. **Anomalías (`Anomaly Monitor`)**
   - Filterable by severity (`ALTA`, `MEDIA`, `BAJA`) and month.
   - Alert banner (`role="alert"`) for high-severity spikes/drops (e.g., *Marketing spike*, *Ingreso drop*, *Logística spike*).
   - Cards/Table showing `PERIODO`, `CATEGORIA`, `VALOR OBSERVADO (COP)`, `ESPERADO / Z-SCORE`, and `MOTIVO` clearly tagged `Alerta Estadística`.
4. **Reportes Ejecutivos (`Reports`)**
   - Header displaying the selected period and manual generation / refresh notice (`datafinance_reporte` DAG runs independently from ETL).
   - Structured executive report card showing persisted `GOLD.REPORTES` narrative (`Explicación IA`), generation timestamp, and linked source KPI summary (`Dato SQL`).

## 5. React + Tailwind Component Rules

### Tailwind Static Class Mapping (Mandatory)

Never construct Tailwind utilities dynamically with string interpolation (e.g., ``bg-${tone}-100`` fails Tailwind CSS v4 static scanning). Always use an explicit lookup object:

```jsx
const BADGE_STYLES = {
  sql: "bg-blue-50 text-blue-800 border-blue-200",
  alert: "bg-amber-50 text-amber-800 border-amber-300",
  danger: "bg-red-50 text-red-700 border-red-200",
  positive: "bg-emerald-50 text-emerald-700 border-emerald-200",
  ai: "bg-slate-100 text-slate-700 border-slate-300",
};
```

### Component Primitives (`Density 8/10`)

- **Card Container (static data container — NO `cursor-pointer` unless actionable):**
  `bg-card border border-border rounded-xl p-4 shadow-sm`
- **Actionable Card / Prompt Pill:**
  `bg-card border border-border rounded-xl p-3 shadow-sm cursor-pointer transition-colors duration-150 hover:border-secondary hover:bg-blue-50/40 focus-visible:outline-2 focus-visible:outline-ring`
- **Primary CTA Button:**
  `inline-flex items-center gap-2 rounded-lg bg-primary px-4 py-2 text-sm font-semibold text-on-primary cursor-pointer transition-colors duration-150 hover:bg-blue-900 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-ring disabled:opacity-50 disabled:cursor-not-allowed`
- **Secondary / Filter Button:**
  `inline-flex items-center gap-2 rounded-lg border border-border bg-card px-3 py-1.5 text-sm font-medium text-foreground cursor-pointer transition-colors duration-150 hover:bg-muted focus-visible:outline-2 focus-visible:outline-ring`
- **Input / Select:**
  `rounded-lg border border-slate-300 bg-card px-3 py-1.5 text-sm text-ink transition-colors duration-150 focus:border-primary focus:outline-none focus:ring-2 focus:ring-primary/20`
- **SVG Icons:**
  Use `lucide-react` exclusively (`w-4 h-4` inline, `w-5 h-5` section headers). Zero emojis for UI structure or status indicators.

### React Performance & State Guidelines

1. **Memoization Discipline:** Apply `React.memo` specifically to `PlotlyChart` (expensive DOM/WebGL canvas wrapper) and large data tables; do **not** wrap simple buttons, badges, or inputs in `memo`/`useCallback` without profiling.
2. **Reserve Chart Dimensions (Zero CLS):** Every `PlotlyChart` wrapper MUST enforce an explicit height (`min-h-[320px]` or `h-[340px]`) and render a matching skeleton (`animate-pulse bg-muted rounded-lg`) while data loads.
3. **Accessible Error & Empty States:** Render API/Snowflake/Groq errors with `role="alert"` and clear recovery guidance; render empty filter states explicitly (*"No hay datos suficientes para el periodo o filtro seleccionado"*).

## 6. Plotly.js Data Visualization Spec

Configure every Plotly layout using the shared theme constants so charts harmonize with Tailwind tokens:

| Series / Meaning | Hex | Usage |
|---|---|---|
| Ingresos | `#059669` | Positive bars / primary revenue line |
| Gastos | `#DC2626` | Expense bars / cost comparison line |
| Utilidad / Net | `#1E40AF` | Net profit line or highlight bar |
| Secondary / Baseline | `#3B82F6` | Reference / previous period |
| Anomaly / Threshold | `#D97706` | Alert markers & threshold dashed lines |
| Categorical Palette | `["#1E40AF", "#059669", "#D97706", "#3B82F6", "#64748B", "#DC2626", "#0D9488"]` | Category & area breakdowns |

**Layout Defaults:**
- `paper_bgcolor: "transparent"`, `plot_bgcolor: "transparent"`
- `font: { family: "Fira Sans, sans-serif", color: "#475569", size: 12 }`
- Gridlines: `#E2E8F0` (`1px`), zero-line `#CBD5E1`
- Hover labels: dark slate `#0F172A` background with `#FFFFFF` `Fira Code` tabular-nums text (`hovermode: "x unified"` for time-series).
- `config={{ responsive: true, displayModeBar: false }}` on compact cards (`displaylogo: false` everywhere).

## 7. Motion & Reduced-Motion Budget

- **Dial:** `3/10` (Subtle) — prioritize instantaneous filter responsiveness over decorative animation.
- Transitions limited to `150ms–200ms` (`transition-colors duration-150`, `transition-opacity duration-200`) on hover, focus, tab switches, and collapsible SQL drawers.
- **No layout-shifting hover transforms** (`scale` or large `translateY`) inside dense KPI grids or tables.
- Respect `@media (prefers-reduced-motion: reduce)` (`motion-reduce:transition-none motion-reduce:animate-none`).

---

## 8. Anti-Patterns (Do NOT Use)

- ❌ Ornate marketing-site sections (hero videos, client logo carousels, pricing/sales CTAs)
- ❌ Unfiltered static views without period/category/area controls
- ❌ Dynamic Tailwind class interpolation (`bg-${variant}-500`)
- ❌ Mixing AI prose and SQL figures without `Dato SQL` / `Explicación IA` / `Alerta Estadística` labels
- ❌ Unformatted currency numbers without `COP` unit or `tabular-nums`
- ❌ Emojis as structural or status icons (use `lucide-react` SVGs)
- ❌ Missing `cursor-pointer` on buttons/tabs, or adding `cursor-pointer` to non-clickable cards
- ❌ Visual-only error states without `role="alert"` / `aria-live`
- ❌ Fixed navbars overlapping content or horizontal body overflow on `375px` viewports
